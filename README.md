# rudimentary-memory-allocator
A simple heap memory allocator made using the following tutorials:

- https://www.sunshine2k.de/articles/coding/cmemalloc/cmemory.html#TOP.
- https://arjunsreedharan.org/post/148675821737/memory-allocators-101-write-a-simple-memory.

The former being followed more due to being OS agnostic.

This project was made for study and learning memory management, i learned a lot and might keep working on it, making it better or actually usable with OS calls
